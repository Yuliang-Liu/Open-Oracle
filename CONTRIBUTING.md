# Contributing to Open-Oracle

Thank you for helping maintain Open-Oracle.

## Add a paper or dataset

Please include the following information:

1. Title, authors, venue and year, and task category.
2. Official paper link first; add arXiv, OpenReview, or DOI if available.
3. Code, dataset, project page, or demo links if public.
4. A one-line summary of the contribution.

## Style

- Keep README concise and put long bibliographies in `PAPERS.md`.
- Prefer stable publisher, arXiv, OpenReview, GitHub, Hugging Face, Figshare, or official project links.
- Use task-oriented sections rather than purely chronological lists.
- Avoid duplicating one paper in many sections unless it is genuinely cross-task.
